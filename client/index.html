📖 คู่มือ (Expert Manual)

⚠️ ทุกโมดูลมีป้าย EDITION (A/B/C) ปั๊มอยู่ — ให้ถาม A ก่อนเสมอว่าเห็น Edition อะไร แล้วดูกฎเฉพาะ Edition นั้น ห้ามข้าม

🔌 Wire Module

Edition A

  • ถ้าไม่มีสายสีแดงเลย → ตัดสาย เส้นที่ 2
  • ถ้าสายเส้นสุดท้ายเป็นสีขาว → ตัด เส้นสุดท้าย
  • ถ้ามีสายสีแดงมากกว่า 1 เส้น → ตัดสาย สีแดงเส้นสุดท้าย
  • นอกเหนือจากนี้ → ตัด เส้นแรก

Edition B

  • ถ้าจำนวนสายทั้งหมดเป็นเลขคู่ → ตัด เส้นกลาง (นับจากซ้าย ถ้าเศษให้ปัดลง)
  • ถ้าจำนวนสายเป็นเลขคี่ และมีสายน้ำเงินมากกว่าเหลือง → ตัด สายน้ำเงินเส้นแรก
  • นอกเหนือจากนี้ → ตัด เส้นสุดท้าย

Edition C

  • ถ้าสายเส้นแรกกับเส้นสุดท้ายสีเดียวกัน → ตัด เส้นที่ 2
  • ถ้ามีสายสีดำพอดี 1 เส้น → ตัด สายสีดำเส้นนั้น
  • นอกเหนือจากนี้ → ตัด เส้นสุดท้าย

🔘 Button Module

Edition A

  • ปุ่ม สีแดง ข้อความ DETONATE → กดค้างไว้ แล้วปล่อยตอนตัวเลขนับถอยหลังลงท้ายด้วย 5
  • ปุ่ม สีน้ำเงิน (ข้อความอะไรก็ได้) → กดครั้งเดียวแล้วปล่อยทันที
  • นอกเหนือจากนี้ → กดค้างไว้อย่างน้อย 3 วินาที แล้วค่อยปล่อย

Edition B

  • ข้อความ HOLD (สีอะไรก็ได้) → กดค้างไว้ แล้วปล่อยตอนตัวเลขลงท้ายด้วย 1
  • ปุ่ม สีเหลือง → กดครั้งเดียวแล้วปล่อยทันที
  • นอกเหนือจากนี้ → กดค้างไว้อย่างน้อย 5 วินาที

Edition C

  • ปุ่ม สีขาว ข้อความ ABORT → กดครั้งเดียวแล้วปล่อยทันที
  • ข้อความ PRESS (สีอะไรก็ได้) → กดค้างไว้ แล้วปล่อยตอนตัวเลขลงท้ายด้วย 9
  • นอกเหนือจากนี้ → กดค้างไว้อย่างน้อย 2 วินาที

💡 Light Module

ถามสี + จังหวะกระพริบ (ช้า/เร็ว) ของแต่ละดวง แล้วบอกว่าควรติดหรือดับ (ต้องตั้งให้ถูกทุกดวงพร้อมกันก่อนกดยืนยัน):

Edition A

สีกระพริบช้ากระพริบเร็ว
🔴 แดงติด (On)ดับ (Off)
🔵 น้ำเงินดับ (Off)ติด (On)
🟡 เหลืองติด (On)ติด (On)

Edition B (ตารางกลับด้าน)

สีกระพริบช้ากระพริบเร็ว

🔵 น้ำเงินติด (On)ดับ (Off)
🟡 เหลืองดับ (Off)ดับ (Off)

Edition C (ไม่สนสี/จังหวะ — นับรวมทั้งหมด)

นับจำนวนดวงที่ ติด อยู่ตอนเริ่ม (ก่อนกดอะไร) — ถ้าเป็นเลขคู่ ตั้งติดหมดทุกดวง, ถ้าเป็นเลขคี่ ตั้งดับหมดทุกดวง

🧩 Logic Module

โมดูลนี้อ่านค่าจาก Wire Module และ Button Module ในระเบิดลูกเดียวกัน (ดูจากที่ A อธิบายมาได้เลย ไม่ต้องคำนวณซับซ้อน — edition ของ Wire/Button เองไม่เกี่ยวกับข้อนี้):

Edition A (AND)

  • CHECK A = จำนวนสายไฟสีแดงในโมดูล Wire เป็นเลขคี่
  • CHECK B = สีปุ่มในโมดูล Button เป็นสีแดง หรือ สีน้ำเงิน

กด YES ก็ต่อเมื่อ CHECK A และ CHECK B เป็นจริงทั้งคู่ — นอกเหนือจากนี้กด NO

Edition B (XOR)

  • CHECK A = จำนวนสายไฟทั้งหมดในโมดูล Wire มากกว่า 4 เส้น
  • CHECK B = ข้อความปุ่มในโมดูล Button เป็น HOLD หรือ PRESS

กด YES ก็ต่อเมื่อ CHECK A กับ CHECK B เป็นจริงข้อใดข้อหนึ่งเท่านั้น (ไม่ใช่ทั้งคู่ ไม่ใช่ไม่มีเลย) — นอกเหนือจากนี้กด NO

Edition C (NOR)

  • CHECK A = มีสายไฟสีขาวอยู่ในโมดูล Wire อย่างน้อย 1 เส้น
  • CHECK B = สีปุ่มในโมดูล Button เป็นสีเหลือง

กด YES ก็ต่อเมื่อ CHECK A และ CHECK B เป็นเท็จทั้งคู่ — นอกเหนือจากนี้กด NO
